# Веса эксперимента

Исходный файл: `VeRi_clipreid_ViT-B-16_60.pth` из официальной таблицы
[Syliz517/CLIP-ReID](https://github.com/Syliz517/CLIP-ReID).
Ноутбук проверяет его SHA-256 перед загрузкой. Без файла обучение не начинается.
Сырые внешние датасеты не скачиваются. Большие веса и временные файлы исключены
из Git; параметры и результаты сохраняются в соседнем `results/`.
