## Запуск

Открыть `../train_yolo11_masks.ipynb`. В первой кодовой ячейке:

```python
RUN_TRAINING = True
RESUME = False
RUN_HOLDOUT = False
```

Остальные пути уже настроены. Выполнить Run All в ядре проекта. Если используется
Mac с доступным MPS, в выводе ожидается `Device: mps`; CPU не подменяется скрытно.
Обучение на этих кадрах в ходе приёмки **не запускалось**, `runs/` не создан.
