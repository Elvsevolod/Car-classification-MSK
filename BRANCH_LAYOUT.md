# Разделение продукта и обучения — 2026-09-27

- **main** — актуальный продукт: API, React UI, PostgreSQL, Docker, автономный экспорт,
  профиль **MVP_fusion_v25**, все необходимые frozen ONNX, runtime-тесты и документация.
- **fine-tuning** — обучение, HPO, notebooks, экспериментальный inference, конфигурации,
  завершённые исследовательские отчёты и код воспроизведения.

Приложение запускать из main. Эта ветка сохраняет свой исторический backend и evaluator
для воспроизводимости экспериментов; это не альтернативная актуальная сборка продукта.
Не сливать main целиком в рабочую копию с запущенным обучением: замороженные эксперименты
проверяют точные байты исходников, моделей и контрольного приложения.

Ночная серия v36: `OSNet-AIN-x1.0/variant_36_transreid_night/train_transreid_night.ipynb`.
Её код и конфигурация включены в эту ветку. Каталог текущего
`runs/night_v1/` исключён из публикации, пока расчёт не завершён.
Исторические notebooks могут содержать результаты на момент сохранения; это не
обещание воспроизведения качества без локальных данных и промежуточных артефактов.

NiVe1303, organizer dataset, окружения, секреты, новые обучающие checkpoint,
эмбеддинг-кэши и служебные lock/tmp остаются локально. Уже существовавшие в истории
ветки бинарные файлы не удалялись и история Git не переписывалась.
Для финального продукта ONNX опубликованы в main; они не требуют обучения при запуске.

Каталог `reproduction/` — точная прежняя копия исходников воспроизведения legacy/R1,
перенесённая сюда из продуктовой рабочей копии. SHA256 внутри `reproduction/source/`
сохранены; текущие эксперименты развиваются в корневом `training/`.

Подробности продукта:
[main](https://github.com/Elvsevolod/Car-classification-MSK/tree/main),
[отчёт v25](https://github.com/Elvsevolod/Car-classification-MSK/blob/main/docs/MODEL_REPORT.md).
После доказанного улучшения в main переносится только зафиксированная модель,
необходимый inference-код, тесты и её подтверждённые метрики; полная история обучения
остаётся здесь. Продвижение новой модели — отдельное решение.
