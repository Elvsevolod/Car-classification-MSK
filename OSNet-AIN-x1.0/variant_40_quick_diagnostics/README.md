# v40 — быстрые G1/G2 и BN

Открыть `quick_fusion_bn.ipynb` в существующем окружении Mac, нажать **Run All**.
Рабочий v25, исходные bbox, CSV, веса и старые runs не изменяются.

Входы: сохранённые feature banks v34/v38 и подготовленная локальная папка
`research_transfer/v41_inputs`. Если её нет на исходном Mac, собрать через
`python -m training.research_inputs`; сборщик проверит исходные байты, не обучая модели.
Этот сборщик не заменяет перенос весов/данных на чистый Windows-клон.

## Что выполняется

1. Компонентные тесты в отдельном процессе с отключённой ORT-телеметрией.
2. 17 calibration-вариантов: контроль и N1/T12 × G1/G2 × веса .02/.05/.10/.20.
   G1 добавляет raw-distance эксперта после графа v25; G2 сохраняет Jaccard-компонент v25,
   меняя только смесь raw-distance. Scale эксперта = `(1-cosine)/2`, графовые distances —
   исходная нормировка v25. Нулевой вес обязан точно повторить порядок контроля.
3. Выбор по calibration, затем validation только контроля и выбранного варианта.
   Это наблюдавшиеся development-разбиения, а не новый независимый тест.
4. R1 и N1: исходный вариант против одного детерминированного train-only прохода пересчёта BN.
   Только 740 primary train-ID; reset running statistics, cumulative momentum, batch32,
   dropout выключен, параметры и головы не обучаются. Последний singleton объединяется
   с предыдущим изображением. Ни holdout, ни gallery/test не обновляют BN.
5. Standalone raw/graph и фиксированная смесь с C_primary на прежних трёх primary draws.

C_primary — B0_208 seed20260915 step800 + три R1_256 step800, веса .5/.5.
Все четыре обучались на том же primary train. Это доступный fold-matched аналог состава
v25, **не точная копия исторического рецепта/удачного checkpoint MVP и не метрика релиза**.

Отказы, threshold и candidates в fusion неизменны. При отказе ranking всё равно содержит 10 ID.
BN-этап не подбирает threshold и не считает новую candidate-policy.

Прогресс печатается; завершённые этапы проверяются и переиспользуются. Результаты:
`runs/quick_v1/`, компактный `quick_v1_analysis.zip`. Для переноса модели сохранить и
каталог run: в компактном ZIP намеренно нет бинарных весов/признаков.

Слово «быстрый» означает отсутствие оптимизации весов. Encoder-forward для контроля
и BN требует времени; гарантированной длительности на Mac нет.
