# v44 — T01 из промежуточной копии v41 против рабочего v25

Запуск: `validate_t01_vs_v25.ipynb` → kernel основной проектной `.venv` → Run All.
Ноутбук предназначен для основного Mac, а не для работающего сейчас Mac mini.

Это **проверка готовых весов, не обучение**. Фиксированы T01 step2883 / rung10,
90% признаков v25 + 10% T01 перед реранкингом, k1=20, k2=3, lambda=0,5.
Исходные кандидаты, их confidence, отказы и threshold 0,534365177154541 сохранены.
Другие checkpoints, веса смешивания или пороги на validation не перебираются.

Выполняются проверки компонентов, контроль SHA-256/источников/разбиений, воспроизведение
32 признаков T01 с Mac mini, свежий extract T01 и всех четырёх энкодеров v25, два полных
экспорта и сравнение метрик/per-query решений. Исходная validation: 309 query,
896 gallery; она ранее наблюдалась и не является новым независимым тестом.

## Нужные входы

- `mac_m4_v1` рядом с основным `Car-classification-MSK`: переданный через AirDrop снимок.
  Нужны manifest, trial_plan, trial.json, готовый `step_002883.pt` T01 и его `rung_10`.
  `resume_*.pt` для этого сравнения не используются.
- Соседний `Car-classification-MSK-main` с действующим `MVP_fusion_v25`.
- В основном проекте: dataset, artifacts/splits.json, исторические v24/v25 и
  `research_transfer/v41_inputs/inputs.json`.

Новые зависимости, NiVe-изображения, pretrained-веса DeiT, сеть или PostgreSQL не нужны.
Модель создаётся без скачивания и строго загружает все тензоры готового checkpoint.
Нужно не менее 1 GiB свободного места. Временного лимита нет.

## Выходы и продолжение

`runs/validation_v1` содержит frozen_candidate, manifest, проверенные признаки обеих
систем, submission.csv/candidates.csv/embeddings.npy для каждой системы, results.json
и REPORT.md. Все query получают 10 разных gallery-ID, включая отказы; отказ — отсутствие
строки в candidates.csv. Вектор кандидата: реальные 2432 float32 координаты.

`validation_v1_analysis.zip` — компактный отчёт без весов и NPY. Никакие прежние runs
не перезаписываются. При прерывании можно повторить Run All с тем же RUN_NAME:
завершённые этапы проверяются и переиспользуются с явной пометкой, не как новые замеры.
Если изменились исходники/входы, не ослаблять проверки: сначала выяснить причину.

Программный запуск из корня проекта:

```bash
.venv/bin/python -m training.transreid_t01_validation --device mps --run-name validation_v1
```

## Ограничения

Кандидат требует пяти энкодеров вместо четырёх. ONNX-экспорт, скорость на целевой GPU
и интеграция в продукт не входят в эту проверку. Даже положительный mAP не переключает
MVP автоматически. Рабочий v25, его веса, исходные bbox, validation и очередь Mac mini
не изменяются. После стоп-кода нельзя обновлять сданные материалы; исследование и
решение о допустимой публикации остаются отдельными действиями.
