## Воспроизведение и диагностика

Из сохранённых признаков повторены ранжирования всех 32 завершённых этапов по шести
политикам на трёх разбиениях — 106 560 query-policy случаев, включая повторы контроля.
Полная битовая эквивалентность между компьютерами для всех моделей не подтверждена.

Дополнительный запуск исходной функции score_features для T01, T07 и R50 VehicleID
дал **точное совпадение всех метрик и per-query записей, включая top-10**.
У части слабых моделей есть расхождения порядка почти равных результатов. Например:

- R50 VERI-Wild: на первом разбиении standalone graph mAP отличается на -0,000270270;
  на третьем изменился raw top-10 одного query без изменения метрики.
- T10 P8K2 soft-triplet LR 0,0003: standalone graph top-10 отличается у 123/142/139
  query на трёх разбиениях. Средний graph mAP локально 0,020086441 вместо 0,020428098.
  Системные G1/G2/pre_graph метрики воспроизвелись. Median cosine между разными
  изображениями 0,999993: признаки почти одинаковы, что указывает на коллапс.

Версии основных Python-пакетов совпадают; версии macOS различаются (15.3.1 / 15.7.3),
как и процессоры. Конкретная причина численных расхождений полностью не установлена.
Допуски, метрики, исходные результаты и пороги не менялись.

Все шесть завершённых SupCon-вариантов TransReID выше контроля по G2; все пять
завершённых soft-triplet вариантов ниже. Ни один из 11 завершённых NiVe/own-only
вариантов не превысил C_primary по G2. Иногда NiVe немного лучше сопоставимого
own-aux контроля, но не всей контрольной системы. Domain-specific BN ещё не проверен
этой копией. Замороженные DINOv2 также не обошли контроль; их адаптация впереди.
