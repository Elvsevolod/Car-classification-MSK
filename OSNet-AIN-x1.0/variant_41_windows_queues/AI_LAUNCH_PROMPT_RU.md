# Промпт: запуск v41 на Mac mini M4, 16 ГБ

Ты работаешь на моём Mac mini M4 с 16 ГБ объединённой памяти. Я перенёс через
AirDrop всю папку «Хакатон мск сентябрь» с другого Mac. Нужно подготовить
локальное окружение и запустить готовые исследования Vehicle ReID через Run All.
Не придумывай другую сетку: запускаем существующий v41, рабочий MVP не меняем.

1. Найди перенесённую папку, внутри неё Car-classification-MSK, затем
   OSNet-AIN-x1.0/variant_41_windows_queues. Название windows историческое;
   сейчас нужен train_mac_m4_queues.ipynb, а не train_windows_queues.ipynb.
   Прочитай README.md и SOURCES.md. Не работай в Car-classification-MSK-main.
   Не делай git pull/reset/checkout/merge/push: нужные локальные изменения уже
   перенесены через AirDrop, они могут ещё не быть в удалённой ветке.
2. Дождись полного копирования. Проверь наличие
   research_transfer/v41_inputs/inputs.json и weights/ внутри v41.
   ZIP повторно распаковывать не нужно. Исходные данные и контрольные checkpoints
   уже в папке; если чего-то не хватает, сообщи о неполном переносе.
   Не заменяй отсутствующие контрольные веса случайными/похожими моделями.
3. Не используй перенесённую .venv или .venv-rtx4060. Запусти Start_v41_Mac.command:
   он создаёт новую .venv-v41-m4, устанавливает requirements-mac.txt,
   выполняет MPS preflight и открывает JupyterLab. Если Python 3.11 arm64 отсутствует,
   помоги установить его на этот Mac с моего согласия; Rosetta/x86 Python не подходит.
   Не отключай Gatekeeper и другую системную защиту целиком ради запуска скрипта.
4. Выбери kernel Car ReID Mac M4. Пути вычисляются относительно нового корня:
   старые /Users/... из provenance не нужно массово исправлять в исторических файлах.
   Проверки SHA256 обнаружат повреждение данных; не отключай их и не меняй hashes.
5. Проверь свободный диск: желательно ещё 50 GiB после переноса. Закрыть тяжёлые
   приложения можно только с моего согласия. Не удаляй checkpoints/датасеты для
   освобождения места и не завершай чужие процессы. Launcher удерживает Mac от
   автоматического сна только пока работает Jupyter; системные настройки не меняет.
6. Нажми Run All в train_mac_m4_queues.ipynb. RUN_NAME = mac_m4_v1, device=mps.
   Не ставь timeout, при автоматическом исполнении отключи лимит времени ячеек.
   Не запускай параллельно второй runner или CLI. Сохрани выполненный notebook.
   Очереди: длинный TransReID; NiVe BN/alpha с контролями; DINOv2/автомобильный R50-IBN.
   Они чередуются на одной Apple GPU; не обещай завершение за одну ночь.
7. Сохрани float32, AMP/fast math/CPU fallback выключены. Лимит MPS allocator —
   0.85 от recommended working set; не делай его нулевым/неограниченным и не обходи OOM.
   При нехватке памяти не меняй P/K, resolution, loss или сетку молча: runner запишет
   failed и продолжит. При общей ошибке preflight остановись и покажи причину.
8. Второй датасет — NiVe1303 v1, Ruozheng LI, CC BY 4.0:
   https://data.mendeley.com/datasets/42wv2svztx/1 (DOI 10.17632/42wv2svztx.1).
   17 070 train-фото уже включены. Test/masks не использовать. Не отправляй датасеты,
   веса или организаторские изображения в Git/сторонние сервисы. Интернет нужен
   только для пакетов и недостающих весов из официальных URL в коде.
9. Не обучай на holdout/calibration/validation/test, включая BN/self-supervised
   адаптацию. Не меняй bbox, ground truth, candidate-policy и threshold. Не добавляй OCR,
   камеры/время/имя файла как вход модели. Camera-aware TRAIN sampler уже предусмотрен.
10. Для продолжения после штатного Interrupt/Restart используй тот же RUN_NAME и
    неизменное окружение/код на этом Mac. Не удаляй runs и не продолжай Windows-run
    внутри MPS-run. Изменение runtime требует нового имени и отдельного сравнения.
11. После завершения проверь results.json/REPORT.md и список failed. Передай обратно
    mac_m4_v1_analysis.zip и mac_m4_v1_full_results.zip, их SHA256 JSON,
    а также выполненный notebook. Не копируй всю папку поверх исходного проекта.
    Сохрани локальный run, пока я не подтвержу, что архивы получены и проверены.

Цель — получить пригодные для анализа результаты и реальные веса. Внутренний
C_primary не является финальным качеством MVP_fusion_v25; автоматического переключения нет.
