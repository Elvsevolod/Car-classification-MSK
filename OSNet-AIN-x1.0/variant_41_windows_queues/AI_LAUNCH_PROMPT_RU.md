# Промпт для запуска на втором компьютере

Ты работаешь на моём Windows-компьютере с NVIDIA RTX 4060 8 GB. Нужно подготовить
окружение и запустить уже реализованные исследования Vehicle ReID. Не придумывай
новый план обучения: выполни подготовленный v41 и сохрани результаты для передачи
на другой компьютер. Сначала прочитай README и SOURCES в
`OSNet-AIN-x1.0/variant_41_windows_queues` ветки `fine-tuning` репозитория
https://github.com/Elvsevolod/Car-classification-MSK.

1. Найди клон и проверь ветку/локальные изменения. Не стирай чужие изменения и не
   переключай dirty-копию принудительно. Если клона нет, клонируй `fine-tuning`.
   Рабочий продукт в main не менять. Push/merge из этого запуска не выполнять.
2. Найди переданный мной `v41_inputs.zip`. Проверь SHA256 и размер по INPUT_PACKAGE.json.
   Если архива нет, спроси, где он находится. Не пытайся восстановить наши обученные
   контрольные веса случайными весами или скачиванием другой модели.
3. Подготовь Python 3.11 x64 и отдельную `.venv-rtx4060` через setup_windows.ps1.
   Не устанавливай CPU-версию PyTorch и не меняй закреплённые версии без согласования.
   Проверь `torch.cuda.is_available()`, имя GPU, VRAM, свободный диск (желательно 50 GB)
   и отсутствие другого тяжёлого GPU-процесса. Не завершай чужие процессы.
4. Распакуй через `python -m training.research_inputs --unpack <путь-к-v41_inputs.zip>`
   из нового окружения. Конечный путь `research_transfer/v41_inputs/inputs.json`.
   Инструмент проверяет байты и переносимые пути. Не отключай проверки для продолжения.
5. В данных используется добавленный вручную NiVe1303 **v1**, автор Ruozheng LI,
   CC BY 4.0. Официальная ссылка: https://data.mendeley.com/datasets/42wv2svztx/1
   DOI 10.17632/42wv2svztx.1. Его train-фото уже есть во входном архиве. Если требуется
   отдельное скачивание, используй только этот источник и train/<ID>/*.jpg, не test/masks.
   Ни этот датасет, ни organizer images не отправлять в Git или сторонним сервисам.
6. Запусти тесты, затем `train_windows_queues.ipynb` через Run All, kernel Car ReID RTX 4060.
   Альтернатива — тот же runner `python -m training.research_gpu --inputs research_transfer/v41_inputs --run-name rtx4060_v1`.
   Не запускай notebook и CLI одновременно. Обеспечь видимый прогресс и сохранение
   выполненного notebook. Не ставь timeout; для автоматического исполнения notebook
   отключи лимит времени ячейки. Не меняй режим сна Windows без моего согласия;
   предупреди, если сон может прервать работу.
7. Сохрани три независимые очереди: длинный TransReID, NiVe BN/alpha с контролями,
   DINOv2 и автомобильный R50-IBN. Runner сам чередует первые опыты и продолжает лучших.
   Не использовать DINOv3 с недоступным доступом. Внешние веса — только официальные
   URL, которые зафиксированы в коде. Не принимать лицензии/условия аккаунта от моего имени.
8. При OOM не уменьшай batch, resolution или P/K молча; при ошибке весов не включай
   strict=False. Runner запишет failed и продолжит остальные опыты. Не выдавай failed
   за нулевую метрику или успешное завершение. Если ломается общий preflight, остановись
   и покажи ошибку; пороги, допуски, разбиения и контрольные суммы менять нельзя.
9. Не обучаться на holdout/calibration/validation/test, включая BN/self-supervised
   адаптацию. Не менять bbox, ground truth, candidate-policy и threshold. Не включать
   OCR, имена файлов, камеры/время в вход модели. Train sampler может использовать
   camera_id только для выбора обучающих положительных пар, как уже реализовано.
10. При штатной остановке продолжай тот же RUN_NAME с тем же кодом/окружением после
    завершения старого процесса. Не удаляй runs, checkpoints и manifests. Не менять
    конфигурацию ради продолжения; для изменения нужен отдельный согласованный run.
11. После завершения проверь results.json/REPORT.md: сколько complete/failed, какие
    очереди реально отработали. Проверь ZIP и SHA256. Передай мне
    `rtx4060_v1_analysis.zip`, `rtx4060_v1_full_results.zip` и их SHA256 JSON, а также
    выполненный notebook. Не удаляй исходную папку run до подтверждения получения.

Цель — получить пригодные для анализа результаты и реальные веса. Не заявляй новый
рекорд MVP по внутренней метрике C_primary и не переключай релиз автоматически.
