# Аудит OSNet: ошибки и точные маски

[Notebook](audit_osnet.ipynb). Изолированная диагностика без обучения или подмены MVP.

## Уже выполнено

Полная текущая outer validation: 309 query / 896 gallery, официальный evaluator.
Повторно получены raw mAP@10 **79.0162%**, reranked **81.4689%**,
F1 **72.8606%**, TNR **79.0323%**. Порог0.5948754549026489 и rerank20/3/0.5
сохранены, не подбирались по этому аудиту.

В `results/errors.json` — 111 ошибочных решений:

- 73 отказа известному автомобилю;
- 25 принятых неверных identity для известных query;
- 13 принятых неизвестных query.

Это объединённый отчёт ошибок retrieval/отказа, **не число только неверных Top-1**.
В `errors.html` показаны первые60 карточек: query, Top-5 и пример верного
cross-camera gallery. В JSON также сохранены размеры кропов и confidence.
Из HTML можно визуально разбирать ракурс, перекрытия и похожие машины; автоматических
достоверных меток этих причин у нас нет.

## Точные маски требуют разметки

Организаторы не дают координаты номеров. HTML-инструмент
`results/annotate_masks.html` создан для **126 кропов** случайных32 identity:
32 query +94 gallery. Выбор не зависит от ошибок OSNet.

1. Открой HTML в обычном браузере локально. Интернет/сервер не нужны.
2. Сверь целевую машину по зелёному BBox организаторов на полном кадре слева.
   Справа показан соответствующий кроп: обведи на нём мышью каждую уже
   анонимизированную область; не угадывай невидимый номер. На узком экране панели
   расположены друг под другом. Полный кадр — только ориентир, маски рисуются на кропе.
3. Нажми «Проверено» для каждого кадра, в том числе без таких областей.
4. Скачай `masks.json`. Можно сохранять промежуточный файл и загружать обратно.
5. Загрузить готовый JSON через notebook FileUpload или положить его в `results/`.
6. Выполнить ячейку парной проверки.

Координаты — целые crop-relative `[x1,y1,x2,y2]` с исключёнными правой/нижней
границами, **до resize**. Исходные фотографии никогда не перезаписываются.
Проверяются границы, fingerprint, SHA-256 кадров, BBox и полнота проверки
всех query/gallery этого маленького протокола. Непроверенные маски блокируют расчёт.
Показ полного кадра не меняет fingerprint, кропы или формат `masks.json`:
ранее сохранённая разметка совместима с обновлённым интерфейсом.

## Результат проверки

`mask_results.json`: метрики before/after при одинаковых query/gallery, весах,
пороге и параметрах reranking; delta mAP@10, F1/TNR, изменения Top-1,
cosine исходного/замаскированного embedding, покрытие и hashes.

**20 сентября 2026: ручная разметка получена и парный аудит выполнен.**
В `results/masks.json` — 126 проверенных кропов и 140 прямоугольников из
пользовательского `masks-6.json`. Происхождение сохранено в
`results/masks_provenance.json`, выводы — в [MASK_AUDIT_RESULTS.md](MASK_AUDIT_RESULTS.md).
Без реранкинга mAP@10 изменился с 97,2283% до 96,6728% (−0,5556 п.п.),
с реранкингом — с 99,0476% до 99,4505% (+0,4029 п.п.). F1/TNR не изменились.

Никакие нижние proxy-прямоугольники за точные маски не выдаются. Абсолютные метрики маленькой
галереи нельзя сопоставлять с основной outer validation; осмысленно парное
изменение до/после на одной подвыборке. Это диагностический тест, а не доказательство
полной независимости от номера и не воспроизведение скрытого контроля жюри.

Большие HTML с изображениями и embedding cache исключены из Git; воспроизводятся
ноутбуком. План, JSON-результаты и разметку можно версионировать отдельно.
