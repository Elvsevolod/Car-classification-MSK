# Результаты

`protocol.json` фиксирует исходные данные и маски; `cache/` содержит только
координаты найденных областей, без копий фото. Каждый `<RUN_NAME>/` хранит
отдельные Optuna DB, истории и настройки. Итоговые метрики выбранного checkpoint
будут в `<RUN_NAME>/selected/evaluation.json`. Метрик нового обучения пока нет.
