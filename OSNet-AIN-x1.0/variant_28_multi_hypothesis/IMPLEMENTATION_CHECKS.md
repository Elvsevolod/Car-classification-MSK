# Проверка реализации v28 — 2026-09-27

Это проверка кода, не результат новой серии экспериментов.

- 169 тестов прошли: v28, v27, v26, v25, dual-role, frozen inference, сравнение моделей и retrieval policy.
- Все 57 scorer сохраняют исходные raw R1 кандидаты и confidence на синтетических входах.
- Проверены permutation/removal query и batch 1/8/16/32 для четырёх семейств и контроля.
- Проверены формулы, пары encoder, signed power, mean только gallery, горизонтальное отражение crop.
- Каждый из пяти возможных типов победителя прошёл полный синтетический controller/export/resume.
- Проверены продолжение независимых задач после ошибки, запрет выбора по неполному набору,
  немедленная остановка при integrity failure и восстановление TTA после прерывания между блоками.
- Реальный `implementation_preflight_v1`: контроль calibration mAP **0.826409928470033**, кандидаты прежние.
- На восьми реальных calibration-изображениях обычный forward совпал с прежним кэшем: max abs error **0.0**.
- Flip forward выдал реальные конечные float32 признаки `(8, 2048)`; они не равны исходным.
- Повторно проверены 2693 защищённых файла и исходные изображения; изменений нет.
- Активный профиль приложения по `release_decision.json` — `MVP_fusion_v25`.
- Notebook валиден, чист от outputs; `runs/multi_hypothesis_v1` при передаче ещё не создан.

Полная сетка на реальных данных, TTA-извлечение полной calibration и validation **не запускались**.
Нового обучения, проверки на GPU/Linux, официального performance benchmark и продвижения модели не было.
