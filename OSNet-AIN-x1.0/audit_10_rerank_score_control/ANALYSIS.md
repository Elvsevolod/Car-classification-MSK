# Итог этапа 1 — 22 сентября 2026

Решение: **не менять MVP**. Сохранить поддержку gallery-соседями как предварительно
полезный контроль для следующих экспериментов. Новую оценку отказа пока не внедрять.

Все настройки выбраны на calibration (307 query / 895 gallery) до расчёта validation
(309 query / 896 gallery). Перебраны 13 заранее заданных вариантов ранжирования и
6 функций уверенности. Код, сетка, выбор и контрольные суммы сохранены отдельно.

## Ранжирование: небольшой положительный сигнал

На calibration победил `support_weight_0.2`: исходный top-50 OSNet, действующий
k-reciprocal 20/3/0.5 и дополнительная поддержка кандидата тремя соседями в gallery.
Его calibration mAP@10 — 78.9072% против 78.7185% у MVP.

На validation:

- mAP@10: **81.4689% → 81.7191%**, прирост **0.2502 п.п.**
- Rank-1: 80.1619% → 80.5668%, то есть один дополнительный правильный top-1 из 247 known-query.
- Rank-5: 88.2591% → 88.6640%.
- При сохранении прежнего отказа F1 и TNR не меняются; TP/FP/FN/TN остаются 149/38/73/49.
- Парный bootstrap 95% для ΔmAP: [+0.0154; +0.5379] п.п.

Это меньше намеченного ориентира +1 п.п. Интервал условен на фиксированной gallery,
а validation уже использовалась в проекте: не называем результат независимым доказательством.
`ranking_only` — заранее запланированная абляция, не повторный выбор алгоритма по validation.

## Отказ: рост F1 не компенсировал падение TNR

Для действующего порядка calibration выбрала `selected_plus_margin`, порог 0.5545714498.
Для нового порядка — `selected_cosine`, порог 0.5506755114.
Исходный режим — max cosine и порог 0.5948754549. Функции уверенности различаются,
поэтому сами численные пороги не следует сравнивать как одну шкалу.

| Validation | MVP | Только новый отказ | Новый порядок + отказ |
|---|---:|---:|---:|
| F1 | 72.8606% | 75.7009% | 75.4098% |
| TNR | 79.0323% | 69.3548% | 69.3548% |
| 0.7F1+0.3TNR | **74.7121%** | 73.7971% | 73.5933% |
| TP / FP / FN / TN | 149 / 38 / 73 / 49 | 162 / 47 / 57 / 43 | 161 / 47 / 58 / 43 |

В combined по сравнению с MVP:

- 13 неверных отказов стали правильными ответами (FN → TP).
- 6 корректных отказов на unknown стали ложными ответами (TN → FP).
- 3 отказа на known стали ответами с неверной машиной (FN → FP).
- 1 правильный ответ стал отказом (TP → FN).

Итого вместо 13 ложных ответов на unknown получено 19 из 62 запросов без пары.
Функция, выигравшая по calibration, не улучшила общую метрику отказа на validation.
Не исправляем это повторной подгонкой порога по validation и не расширяем сетку задним числом.

## Стоимость и маски

Дополнительных весов нет: тот же OSNet ONNX, около 8.35 MiB. Локальный контрольный
CPU-прогон после извлечения эмбеддинга — около 0.25–0.26 мс на query, построение
графа — около 0.10 с. Это измерение экспериментальной реализации с подготовкой
признаков уверенности, не официальный extract-бенчмарк RTX A5000; небольшую разницу
времени не трактуем как доказанный выигрыш скорости.

На 126 original/manual-v2 кропах прежнего аудита combined не показал обвала
ранжирования: original mAP 99.3132%, manual 99.4505%. Эта малая выборка содержит
всего 6 unknown и не выявила ухудшение TNR, заметное на полной validation.
Нельзя заменять ею основную оценку или считать её доказательством независимости от номеров.
