## Повторная подготовка

Если нужно заново получить результаты, выполните из корня проекта:

```bash
python -m backend.infer --dataset /path/to/dataset --output artifacts/export-v25-new --profile MVP_fusion_v25
python -m tools.package_submission --dataset /path/to/dataset --export artifacts/export-v25-new --output artifacts/submission/MVP_fusion_v25_new --source-kit artifacts/reproduction/vehicle-reid-v25-reproduction.zip
```

Для уже готового экспорта достаточно второй команды с нужным путём `--export`.
Архив исходников собирается командой `python pack.py --output /absolute/path/vehicle-reid-v25-reproduction.zip` из [reproduction-kit в fine-tuning](https://github.com/Elvsevolod/Car-classification-MSK/tree/35e6e1f0ffc6f378e924da930fdeccc5841273d1/reproduction-kit) после подготовки по его README. Упаковщик main проверяет хеши комплекта и точное совпадение текущих весов и политик; исторический commit обучения и текущий commit inference записываются раздельно.
Укажите новое имя `--output`: инструмент сохраняет существующие комплекты
и не перезаписывает их. На этом этапе проверка выполняется на Mac/CPU.

Перед упаковкой программа проверяет исходные файлы и модель, повторяет поиск
по эмбеддингам, затем сверяет байты копий и содержимое ZIP. Пять тестов
проверяют этот путь, включая изменённый top-10, неверную confidence,
ложное принятие запроса и защиту существующей папки от перезаписи.
