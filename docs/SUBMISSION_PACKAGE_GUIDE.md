# Памятка команде: ссылки для сдачи

Это внутренняя инструкция ASU Team. Описание решения для экспертов находится в корневом README и `docs/DOCUMENTATION.md`; короткое описание результатов находится в `submission/MVP_fusion_v25/README.md`.

## Что указывать в форме

| Поле | Материал |
| --- | --- |
| Репозиторий | Ссылка на опубликованную версию с кодом, моделями и корневым README |
| Документация | [Актуальная документация](DOCUMENTATION.md) и [PDF-снимок от 28 сентября](ASU_Team_Vehicle_ReID.pdf); обновлённый запуск — [Runbook](RUNBOOK.md) |
| Презентация | [PDF](../presentation/ASU_Team.pdf) или [PPTX](../presentation/ASU_Team.pptx), 15 слайдов, версия от 29 сентября |
| Прототип | Адрес работающего сервиса после размещения |
| Дополнительные материалы | Ссылка на `docs/EXPERIMENT_HISTORY.md` и при необходимости папку результатов |

На присланном скриншоте все поля, кроме дополнительных материалов, обязательны. Организаторы допускают одну ссылку в нескольких полях, если по ней легко найти нужные материалы. Доступ должен быть открыт проверяющим. Это подтверждено общим объявлением, сохранённым в разделе S2 ответов Telegram от 28 сентября.

Репозиторий служит основной точкой входа. Код, документацию, небольшие готовые веса, исходники воспроизведения и файлы результатов можно держать в нём. Датасет с изображениями остаётся отдельно. Презентацию можно разместить в репозитории или доступной папке; прототип получает собственный адрес.

## Зачем сохраняем архивы

Архивы предыдущих этапов остаются готовыми копиями для переноса. Скриншот и сохранённые объявления не устанавливают обязательность ZIP. В репозитории те же исходники и результаты открываются без распаковки.

Старый `artifacts/submission/MVP_fusion_v25_20260928.zip` сохраняет свою первоначальную контрольную сумму и прежнюю памятку. Для организаторов подготовлена папка `submission/MVP_fusion_v25/` с коротким README. Три файла результатов в ней побайтово совпадают с исходным комплектом. Её `SHA256SUMS` учитывает новый README.

Паспорт содержит хеш исходного архива воспроизведения как историческую ссылку на проверенный комплект. Сам обучающий код доступен в [reproduction-kit ветки fine-tuning, коммит 35e6e1f](https://github.com/Elvsevolod/Car-classification-MSK/tree/35e6e1f0ffc6f378e924da930fdeccc5841273d1/reproduction-kit), архив не обязателен для чтения исходников. В main исходники обучения не дублируются.

## Перед заполнением формы

Проверьте доступ к ссылкам без учётной записи автора и добавьте адрес работающего прототипа. Основная точка входа — [main](https://github.com/Elvsevolod/Car-classification-MSK/tree/main); материалы обучения доступны по закреплённой ссылке выше. Публикация репозитория не запускает внешний стенд автоматически. Убедитесь, что комплект презентации соответствует обязательным разделам официального шаблона.

Если итоговым станет другой вариант модели, заново получить три файла результата, паспорт и проверку, затем обновить описание. Результаты v25 сохранить под прежним именем.
